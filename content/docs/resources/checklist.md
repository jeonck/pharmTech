순서대로 지워 나가면 됩니다. 각 항목에서 **무엇을 어떻게 하는지**는 옆의 링크에 있습니다.

전체 흐름과 기간·비용은 [로드맵](../../roadmap/)에, 자주 나오는 질문은 [FAQ](../faq/)에 정리되어 있습니다.

## 0단계 — 시작 전 확인

- [ ] 미국에서 합법적으로 취업할 수 있는 신분인가 → [FAQ · 비자 문제](../faq/#영어와-신분)
- [ ] 고등학교 졸업장 또는 [GED](https://ged.com/)가 있는가 (없다면 취득 계획)
- [ ] 영어로 처방 확인과 환자 응대가 가능한 수준인가 → [처방 읽는 법](../../study/reading/) · [환자 응대 문장](../../study/patient-phrases/)
- [ ] 신원 조회에 걸릴 사항이 있는가 (있다면 미리 [TSBP 규정](https://www.pharmacy.texas.gov/pharmacytechs.asp) 확인)

## 1단계 — 텍사스 트레이니 등록

절차 상세 → [텍사스 주 등록 (TSBP)](../../certification/texas-registration/)

- [ ] [TSBP 온라인 포털](https://www.pharmacy.texas.gov/) 계정 생성
- [ ] [Initial Technician Trainee 신청서](https://www.pharmacy.texas.gov/techtrainee.asp) 제출
- [ ] 수수료 결제 (약 $55)
- [ ] 자동 발송 이메일 3통 수신 확인 (신청서 사본 · 영수증 · 지문 안내)
- [ ] **서비스 코드가 포함된 링크**로 지문 채취 예약 → [지문 안내](https://www.pharmacy.texas.gov/applicants/fingerprint-tech-renewal.asp)
- [ ] 지문 채취 완료 (결과 반영 최대 10 영업일)
- [ ] 등록번호 발급 및 **ACTIVE 상태 확인** → [등록 조회](https://www.pharmacy.texas.gov/dbsearch/)

## 2단계 — 취업 (트레이니)

- [ ] 영문 이력서 1페이지 완성 → [이력서 작성](../../jobs/resume/)
- [ ] 소매 체인 3~5곳 온라인 지원 → [지원처 목록](../../jobs/job-sites/) · [고용주 유형별 특징](../../jobs/employers/)
- [ ] 근처 매장 직접 방문 인사
- [ ] 면접 준비 (STAR 답변 5개) → [면접 준비](../../jobs/interview/) · [회화 문장 플레이](../../study/talk-play/)
- [ ] 채용 확정 · 근무 시작
- [ ] 근무 시간 기록 ([PTCB Pathway 2](../../certification/ptcb/#응시-자격)의 500시간 증빙)

## 3단계 — PTCE 준비

- [ ] [PTCE 출제 범위 PDF](https://ptcb.org/wp-content/uploads/2025/07/PTCE-Content-Outline.pdf) 정독 (2026 개정판) → [무엇이 바뀌었나](../../certification/ptcb/#출제-범위-2026년-1월-6일-개정)
- [ ] 2026 범위를 반영한 교재·문제은행 확보
- [ ] [8주 학습 계획](../../certification/study-plan/) 시작
- [ ] Top 약물 암기 (하루 10개) → [정리표](../../study/top-drugs/) · [플래시카드](../../study/flashcards/)
- [ ] 계산 유형별 반복 → [약국 계산](../../study/calculations/) · [퀴즈 3·4일차](../../study/daily-quiz/)
- [ ] 처방 읽기 연습 → [처방 읽는 법](../../study/reading/) · [조립 플레이](../../study/sig-play/)
- [ ] 연방 법규 정리 (DSCSA 포함) → [4. 연방 법규](../../study/federal-law/)
- [ ] 환자 안전·처방 처리 정리 → [안전](../../study/safety-qa/) · [처방 입력·처리](../../study/order-entry/)
- [ ] 모의고사 4회 이상, 처음 보는 문제에서 85% 달성 → [오늘의 10문제](../../study/daily-quiz/) · [연습 문제 30선](../../study/practice/)
- [ ] [암기 단권화 PDF](/pharmtech-cheat-sheet.pdf) 인쇄해서 들고 다니기

## 4단계 — 시험

시험 구조와 응시 자격 → [PTCE (PTCB CPhT)](../../certification/ptcb/)

- [ ] [PTCB 계정](https://www.ptcb.org/) 생성 및 응시 신청
- [ ] 응시료 $129 결제
- [ ] ATT(Authorization to Test) 수신 확인
- [ ] [피어슨 뷰](https://home.pearsonvue.com/ptcb) 예약 (날짜·센터)
- [ ] 신분증 확인, 시험장 위치·소요 시간 확인
- [ ] 응시 · 합격
- [ ] 공식 성적표·자격증 번호 저장

## 5단계 — 정식 등록 전환

절차 상세 → [정식 등록으로 전환](../../certification/texas-registration/#2-정식-등록으로-전환업그레이드)

- [ ] [TSBP 포털에서 업그레이드](https://www.pharmacy.texas.gov/Upgradetech.asp) 신청
- [ ] 자격증 번호·취득일 입력
- [ ] 수수료 결제 (약 $84)
- [ ] 승인 · Registered Pharmacy Technician 상태 확인 → [등록 조회](https://www.pharmacy.texas.gov/dbsearch/)
- [ ] 고용주에 자격 취득 통보 (시급 조정 요청) → [급여 수준](../../jobs/market/#급여)

## 6단계 — 다음 단계

- [ ] 이력서에 CPhT·등록번호 반영 → [이력서 작성](../../jobs/resume/)
- [ ] 병원·전문약국 지원 시작 → [고용주 유형별 특징](../../jobs/employers/) · [지원처 목록](../../jobs/job-sites/)
- [ ] CE 계획 세우기 (2년 20시간, 텍사스 약사법 1시간 포함) → [FreeCE](https://www.freece.com/) · [Power-Pak C.E.](https://www.powerpak.com/)
- [ ] 갱신일 달력에 등록 ([TSBP 갱신](https://www.pharmacy.texas.gov/techrenewal.asp) 2년 / [PTCB 재인증](https://www.ptcb.org/) 2년)
- [ ] 다음 목표 정하기 (CSPT, IV 조제, 인포매틱스 등) → [채용 시장 · 경쟁력을 높이는 요소](../../jobs/market/#경쟁력을-높이는-요소)
