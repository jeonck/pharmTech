순서대로 지워 나가면 됩니다.

## 0단계 — 시작 전 확인

- [ ] 미국에서 합법적으로 취업할 수 있는 신분인가
- [ ] 고등학교 졸업장 또는 GED가 있는가 (없다면 취득 계획)
- [ ] 영어로 처방 확인과 환자 응대가 가능한 수준인가
- [ ] 신원 조회에 걸릴 사항이 있는가 (있다면 미리 TSBP 규정 확인)

## 1단계 — 텍사스 트레이니 등록

- [ ] TSBP 온라인 포털 계정 생성
- [ ] Initial Technician Trainee 신청서 제출
- [ ] 수수료 결제 (약 $55)
- [ ] 자동 발송 이메일 3통 수신 확인
- [ ] **서비스 코드가 포함된 링크**로 지문 채취 예약
- [ ] 지문 채취 완료 (결과 반영 최대 10 영업일)
- [ ] 등록번호 발급 및 **ACTIVE 상태 확인**

## 2단계 — 취업 (트레이니)

- [ ] 영문 이력서 1페이지 완성
- [ ] 소매 체인 3~5곳 온라인 지원
- [ ] 근처 매장 직접 방문 인사
- [ ] 면접 준비 (STAR 답변 5개)
- [ ] 채용 확정 · 근무 시작
- [ ] 근무 시간 기록 (PTCB Pathway 2의 500시간 증빙)

## 3단계 — PTCE 준비

- [ ] PTCE 출제 범위 PDF 정독 (2026 개정판)
- [ ] 2026 범위를 반영한 교재·문제은행 확보
- [ ] 8주 학습 계획 시작
- [ ] Top 약물 암기 (하루 10개)
- [ ] 계산 유형별 반복
- [ ] 연방 법규 정리 (DSCSA 포함)
- [ ] 모의고사 4회 이상, 처음 보는 문제에서 85% 달성

## 4단계 — 시험

- [ ] PTCB 계정 생성 및 응시 신청
- [ ] 응시료 $129 결제
- [ ] ATT 수신 확인
- [ ] 피어슨 뷰 예약 (날짜·센터)
- [ ] 신분증 확인, 시험장 위치·소요 시간 확인
- [ ] 응시 · 합격
- [ ] 공식 성적표·자격증 번호 저장

## 5단계 — 정식 등록 전환

- [ ] TSBP 포털에서 업그레이드 신청
- [ ] 자격증 번호·취득일 입력
- [ ] 수수료 결제 (약 $84)
- [ ] 승인 · Registered Pharmacy Technician 상태 확인
- [ ] 고용주에 자격 취득 통보 (시급 조정 요청)

## 6단계 — 다음 단계

- [ ] 이력서에 CPhT·등록번호 반영
- [ ] 병원·전문약국 지원 시작
- [ ] CE 계획 세우기 (2년 20시간, 텍사스 약사법 1시간 포함)
- [ ] 갱신일 달력에 등록 (TSBP 2년 / PTCB 2년)
- [ ] 다음 목표 정하기 (CSPT, IV 조제, 인포매틱스 등)
