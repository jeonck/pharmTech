**ExCPT**(Exam for the Certification of Pharmacy Technicians)는 NHA(National Healthcareer Association)가 시행하는 자격시험입니다. 텍사스 TSBP는 **PTCE와 ExCPT 둘 다** 정식 등록 요건으로 인정합니다.

## PTCE와 비교

| 항목 | PTCE (PTCB) | ExCPT (NHA) |
|---|---|---|
| 인지도 | 업계 표준에 가까움. 병원·체인 채용 공고에서 "PTCB certified"를 명시하는 경우가 많음 | 인정되지만 언급 빈도는 낮음 |
| 텍사스 인정 | 인정 | 인정 |
| 문항 수 | 90문항 / 110분 | 120문항(채점 100) / 약 2시간 |
| 응시료 | $129 | $125 내외 |
| 응시 자격 | 교육 프로그램 수료 또는 실무 500시간 | 고졸/GED + 교육 프로그램 또는 실무 경력 |
| 시험 성격 | 법규·안전·계산 비중이 높고 문항이 다소 까다롭다는 평 | 소매약국 실무 위주라는 평 |

## 무엇을 고를까

**PTCE(PTCB)를 기본값으로 두는 것을 권합니다.** 이유는 시험 난이도보다 채용 쪽에 있습니다.

- 병원, 전문약국(specialty), 정맥주사 조제 부서 공고는 대부분 "CPhT (PTCB)"를 요구하거나 우대합니다
- 일부 고용주의 내부 승급 기준이 PTCB 기준으로 작성되어 있습니다
- 주(state)를 옮길 경우에도 PTCB 쪽이 확인 절차가 단순한 편입니다

다만 이미 다니는 회사가 ExCPT 응시료를 지원하거나, 회사 교육 프로그램이 ExCPT와 연계되어 있다면 ExCPT로 시작해도 텍사스 등록에는 아무 문제가 없습니다.
