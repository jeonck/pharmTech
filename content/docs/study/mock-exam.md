실제 PTCE와 같은 **문항 수·시간·도메인 비중**으로 푸는 모의고사입니다. 시험 중에는 정답이 보이지 않고, 제출한 뒤에 도메인별 성적과 오답 해설이 나옵니다.

{{< callout type="info" >}}
**출제 비중은 [2026년 1월 개정 블루프린트](https://ptcb.org/wp-content/uploads/2025/07/PTCE-Content-Outline.pdf)를 따릅니다** — 약물 35% · 환자 안전·품질관리 23.75% · 처방 입력·처리 22.5% · 연방 법규 18.75%. 90문항 기준으로 32 / 21 / 20 / 17문항이 배정됩니다.
{{< /callout >}}

{{< mockexam >}}

## 무엇이 실제 시험과 같고, 무엇이 다른가

| 항목 | 실제 PTCE | 이 모의고사 |
|---|---|---|
| 문항 수 | 90문항 (채점 80 + 사전 테스트 10) | 90문항 전부 채점 |
| 시간 | 110분 | 110분 |
| 형식 | 4지선다, 되돌아가기 가능 | 동일 |
| 합격 | 척도 점수 1400 (1000~1600) | 정답률로 환산한 **근사치** |
| 언어 | 영어 | 한국어 문항 + 영어 용어 |

척도 점수는 PTCB가 문항 난이도로 보정해 산출하므로 정확히 재현할 수 없습니다. 이 화면의 숫자는 정답률을 1000~1600으로 옮긴 참고값이며, **실제 합격선은 대략 정답률 65~70% 부근**으로 알려져 있습니다. 안정적으로 붙으려면 85% 이상을 목표로 하세요.

## 문제은행 구성

{{< sigfig name="exam-blueprint" caption="2026 블루프린트 비중과 문제은행의 도메인별 문항 수" >}}

| 도메인 | 비중 | 다루는 지식영역 |
|---|---|---|
| 약물 | 35% | 제네릭·브랜드·분류, 치료 중복, 상호작용·금기, 용량·제형·경로, 부작용·알레르기, 적응증, 안정성, 보관 |
| 환자 안전·품질관리 | 23.75% | high-alert·LASA, 오류 예방, 약사 개입 사안, 사건 보고, 오류 유형, 감염 관리 |
| 처방 입력·처리 | 22.5% | NDC·처방 요건, 보험 청구·거절, 라벨·보조 라벨, 재고, 조제 흐름 |
| 연방 법규 | 18.75% | 보관·폐기, 규제약물, 기록·서식, 제한 프로그램, 리콜, **DSCSA** |

**처방 입력·처리의 약 1/3은 계산 문항**이며, [약국 계산](../calculations/)에서 쓰는 것과 같은 생성기로 만들어져 **매번 숫자가 바뀝니다.** 답을 외워서 맞힐 수 없습니다.

## 2026 개정에서 달라진 것

- **연방 법규 12.5% → 18.75%** — 이번 개정의 가장 큰 변화입니다. 특히 **DSCSA**(제품 일련번호, T3 문서, 의심 제품 격리)가 새로 들어왔습니다.
- **약물 40% → 35%** — 여전히 가장 큰 도메인이지만 비중은 줄었습니다.
- **빠진 것** — 무균·비무균 조제(compounding) 지식영역, **alligation 계산**, 치료역이 좁은 약물(NTI) 항목.

응시자들이 가장 어려워하는 곳은 **규제약물 규정과 계산**입니다. 이 두 곳은 암기와 반복 외에 방법이 없으니, 도메인 집중 모드로 따로 도세요.

## 이렇게 쓰세요

1. 처음에는 **빠른 점검 20문항**으로 현재 위치를 확인하세요.
2. 도메인별 정답률에서 **70% 미만인 곳**을 학습 노트로 돌아가 다시 보세요.
3. 시험 2주 전부터는 **실전 90문항을 시간 재고** 푸세요. 110분을 실제로 견디는 연습이 필요합니다.
4. **틀린 문제 다시**로 약점만 반복하세요. 계산 문항은 같은 유형이 새 숫자로 나옵니다.
5. 처음 보는 문제에서 **85% 이상**이 안정적으로 나오면 응시해도 좋습니다.
