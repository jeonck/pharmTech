{{< callout type="info" >}}
**상황 → 문장** 한국어 상황을 보고 영어 문장을 고릅니다 · **문장 → 뜻** 영어를 보고 어떤 상황인지 고릅니다 · **섞어서** 두 방향을 번갈아 · **롤플레이 대화** 실제 대화를 따라가며 다음에 할 말을 고릅니다.

## 롤플레이 6가지 상황

| 상황 | 무엇을 보는가 |
|---|---|
| 신규 처방 픽업 | 본인 확인 → 약사 상담 제공 → 서명 순서 |
| 조기 재조제 거절 | 거절 사유 전달과 vacation override 제안 |
| 전화 리필 접수 | 소속 밝히기 → 본인 확인 → 리필 여부 → 후속 조치 |
| 대신 받으러 온 사람 | HIPAA — 확인 절차와 정보 제공의 경계 |
| 일반약 추천 요청 | 업무 범위 — 추천하지 않고 약사에게 넘기기 |
| 처방자 사무실 통화 | 소속 → 환자 → 약 → 요청 → 연락처 순서 |

오답 보기는 **그럴듯하지만 실제로는 문제가 되는 응대**로 만들었습니다. 닫힌 질문으로 본인을 확인하거나, 복용법을 직접 설명하거나, 가족이라는 이유로 진단명을 알려 주는 것들입니다. 틀려 보면서 경계를 익히는 것이 목적입니다.

## 이렇게 쓰세요

1. **소리 내어 읽으세요.** 눈으로 고르기만 하면 카운터에서 입이 안 떨어집니다.
2. 문장 모드는 **상황 → 문장** 방향을 먼저 하세요. 실제 업무가 그 방향입니다.
3. **문장 → 뜻**은 환자·처방자가 하는 말을 알아듣는 훈련입니다. 듣기가 약하면 이쪽을 더 도세요.
4. 롤플레이는 6개를 전부 만점으로 통과할 때까지 반복하세요. 여기서 틀리는 항목이 실제 근무에서 사고가 나는 지점입니다.
5. 진행 기록은 이 브라우저에만 저장됩니다.
