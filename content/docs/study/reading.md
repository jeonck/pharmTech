약어를 "아는 것"과 현장에서 "읽고 말하는 것"은 다릅니다. 이 페이지는 처방 한 줄을 어떤 순서로 해석하고, 그것을 영어로 어떻게 말하는지를 다룹니다.

{{< callout type="info" >}}
한글 발음 표기는 근사치입니다. 정확한 발음은 [MedlinePlus](https://medlineplus.gov/druginformation.html)나 사전의 음성 파일로 확인하세요. **대문자로 표시한 음절이 강세**입니다.
{{< /callout >}}

## 1. sig 한 줄을 읽는 순서

약어는 처방전에 적힌 순서대로 읽는 것이 아니라, **정해진 순서로 재배열**해서 읽습니다.

```text
1 tab po bid x 10d prn pain
│    │  │   │      │   └ 조건
│    │  │   │      └ 기간
│    │  │   └ 빈도
│    │  └ 경로
│    └ 제형
└ 수량
```

**읽는 순서: 동사 → 수량 → 제형 → 경로 → 빈도 → 기간 → 조건**

{{< sigfig name="sig-anatomy" caption="처방전의 약어 뭉치가 라벨 문장의 어느 자리로 가는지 — 이 구조만 잡으면 어떤 처방도 읽힙니다" >}}

> "Take **one tablet** by mouth **twice daily** for **ten days** as needed for pain."
> 원 태블릿 바이 마우스 트와이스 데일리 포 텐 데이즈 애즈 니디드 포 페인

한국어로는 "1정을 경구로 1일 2회, 10일간, 통증 시" — 순서가 같습니다. 이 틀만 잡으면 어떤 처방도 읽힙니다.

### 동사 고르기

{{< sigfig name="form-verb" caption="제형별 라벨 동사 — 점안액에 Take를 쓰면 라벨 전체가 어색해집니다" >}}

| 제형 | 영어 동사 |
|---|---|
| 정제·캡슐·액상 | **Take** |
| 연고·크림·로션 | **Apply** |
| 점안액·점이액·점비액 | **Instill** (또는 Place) |
| 흡입기 | **Inhale** |
| 좌제 | **Insert** |
| 주사 | **Inject** |

라벨에 "Take 2 drops in both eyes"라고 쓰면 어색합니다. 점안액은 **Instill**입니다.

## 2. 빈도 약어를 말로 옮기기

**약어를 글자 그대로 읽지 않습니다.** "비아이디"가 아니라 "twice daily"라고 말합니다.

| 약어 | 라벨·구두 표현 | 발음 |
|---|---|---|
| qd / daily | once daily | 원스 데일리 |
| bid | twice daily | 트와이스 데일리 |
| tid | three times daily | 쓰리 타임즈 데일리 |
| qid | four times daily | 포 타임즈 데일리 |
| q4h | every four hours | 에브리 포 아워즈 |
| q6h | every six hours | 에브리 씩스 아워즈 |
| prn | as needed | 애즈 니디드 |
| ac | before meals | 비포 밀즈 |
| pc | after meals | 애프터 밀즈 |
| hs | at bedtime | 앳 베드타임 |
| stat | immediately | 이미디엇리 |
| ATC | around the clock | 어라운드 더 클락 |

{{< callout type="warning" >}}
**"as needed"는 반드시 이유를 붙입니다.** "as needed" 만으로 끝내지 말고 "as needed **for pain**", "as needed **for cough**"까지 말하세요. 이유 없는 prn은 환자가 남용하기 쉽습니다.
{{< /callout >}}

## 3. 투여 경로 말하기

{{< sigfig name="injection-layers" caption="주사 경로는 바늘이 어느 층에서 멈추는가로 갈립니다 — 각도와 대표 약물" >}}

라벨에서는 라틴어 약어 대신 **환자가 알아듣는 말**로 씁니다.

| 약어 | 라벨 표현 | 발음 | 한국어 |
|---|---|---|---|
| po | by mouth | 바이 마우스 | 경구 |
| sl | under the tongue | 언더 더 텅 | 설하 |
| top | apply to the skin | 어플라이 투 더 스킨 | 피부 |
| inh | inhale by mouth | 인헤일 바이 마우스 | 흡입 |
| pr | rectally | 렉털리 | 직장 |
| pv | vaginally | 배지널리 | 질 |
| sc / subq | subcutaneously | 서브큐테이니어슬리 | 피하 |
| im | intramuscularly | 인트라머스큘러리 | 근육 |
| iv | intravenously | 인트라비너슬리 | 정맥 |

### 눈·귀는 풀어서 말합니다

{{< sigfig name="eyes-ears" caption="환자를 마주 보면 환자의 오른쪽(OD·AD)이 내 왼쪽입니다" >}}

| 약어 | 절대 이렇게 읽지 말 것 | 이렇게 말합니다 |
|---|---|---|
| od | "오디" | **in the right eye** (인 더 라이트 아이) |
| os | "오에스" | **in the left eye** (인 더 레프트 아이) |
| ou | "오유" | **in both eyes** (인 보스 아이즈) |
| ad | "에이디" | **in the right ear** (인 더 라이트 이어) |
| as | "에이에스" | **in the left ear** (인 더 레프트 이어) |
| au | "에이유" | **in both ears** (인 보스 이어즈) |

o와 a 한 글자 차이로 눈과 귀가 바뀝니다. 소리로 구분하려 하지 말고 **eye / ear로 풀어 말하는 습관**을 들이세요.

## 4. 제형 이름 읽기

| 약어 | 영어 | 발음 | 한국어 |
|---|---|---|---|
| tab | tablet | 태블릿 | 정제 |
| cap | capsule | 캡슐 | 캡슐 |
| susp | suspension | 서스펜션 | 현탁액 |
| sol | solution | 솔루션 | 용액 |
| ung / oint | ointment | 오인트먼트 | 연고 |
| cr | cream | 크림 | 크림 |
| supp | suppository | 서포지토리 | 좌제 |
| gtt | drop(s) | 드롭(스) | 방울 |
| syr | syrup | 시럽 | 시럽 |
| elix | elixir | 일릭서 | 엘릭서 |
| inj | injection | 인젝션 | 주사 |
| MDI | metered-dose inhaler | 미터드 도즈 인헤일러 | 정량 흡입기 |

### 서방·장용 표기 읽기

| 표기 | 영어 | 뜻 |
|---|---|---|
| ER / XR / XL | extended release | 서방 |
| SR | sustained release | 서방 |
| CR | controlled release | 제어 방출 |
| DR | delayed release | 지연 방출 |
| EC | enteric coated | 장용 코팅 |
| ODT | orally disintegrating tablet | 구강붕해정 |

말할 때는 "메토프롤롤 **이알**"처럼 알파벳 그대로 읽습니다 — "Metoprolol **E-R**", "Bupropion **X-L**". 이 부분만은 약어로 말하는 것이 표준입니다.

## 5. 숫자와 수량 읽기

숫자를 잘못 말하면 그대로 투약 오류가 됩니다. 약국에서만 통하는 규칙이 있습니다.

### 소수점

| 쓰기 | 말하기 | 이유 |
|---|---|---|
| 0.5 mL | **"zero point five"** | "point five"라고만 하면 5로 들립니다 |
| 1 mg | **"one milligram"** | `1.0`으로 쓰지 않습니다 |
| 2.5 mg | "two point five" | |

**선행 0은 반드시 말하고, 후행 0은 쓰지도 말하지도 않습니다.**

### 여러 자리 숫자

| 숫자 | 안전한 표현 | 피할 표현 |
|---|---|---|
| 15 | **"one five, fifteen"** | "fifteen" 단독 (fifty와 혼동) |
| 50 | **"five zero, fifty"** | "fifty" 단독 |
| 250 | "two fifty" 또는 "two hundred fifty" | |
| 1,000 | "one thousand" | "one K" |

15와 50, 13과 30, 19와 90은 전화로는 특히 잘못 들립니다. **숫자를 한 자리씩 부른 뒤 전체를 말하는 것**이 병원에서 쓰는 방식입니다.

### 단위

| 표기 | 말하기 | 주의 |
|---|---|---|
| mg | milligram | |
| mcg | **microgram** | "mic"이라고 줄이지 않습니다 |
| g | gram | |
| mL | milliliter | "씨씨(cc)"는 쓰지 않는 추세입니다 |
| units | **units** | **절대 "U"라고 말하거나 쓰지 않습니다** |
| mEq | milliequivalent | 밀리이퀴벌런트 |

## 6. 단위 환산 읽고 말하기

환산은 계산 이전에 **문장으로 옮기는 연습**이 먼저입니다.

| 처방 표현 | 읽는 법 | 실제 값 |
|---|---|---|
| `1 tsp` | one teaspoonful | 5 mL |
| `2 tsp` | two teaspoonfuls | 10 mL |
| `1 tbsp` | one tablespoonful | 15 mL |
| `1 fl oz` | one fluid ounce | ≈30 mL |
| `4 fl oz` | four fluid ounces | ≈120 mL |
| `1 pint` | one pint (파인트) | 473 mL (≈480) |
| `1 quart` | one quart (쿼트) | 946 mL (≈960) |
| `1 gallon` | one gallon (갤런) | 3,785 mL |
| `gr 5` | five grains (그레인) | 325 mg |

{{< callout type="warning" >}}
**환자에게는 mL로 말하세요.** "티스푼으로 한 숟갈"이라고 안내하면 환자가 집에 있는 아무 숟가락이나 씁니다. 실제 부피는 3~7 mL까지 차이가 나며, 소아 용량에서는 이 차이가 그대로 과량 투여가 됩니다. 반드시 계량 스푼이나 경구용 주사기를 함께 제공하고 **"5 밀리리터"** 로 안내합니다.
{{< /callout >}}

## 8. 전화로 확인할 때

처방자 사무실이나 다른 약국과 통화할 때는 **철자를 불러 주는 것**이 기본입니다.

> "That's Celexa — **C as in Charlie, E as in Echo, L as in Lima, E, X-ray, A as in Alpha.**"

혼동 쌍(Celexa / Celebrex, hydralazine / hydroxyzine)은 이름만 말하면 반드시 사고가 납니다. 철자와 함께 **용도를 덧붙이면** 확인이 빨라집니다.

> "Celexa, the antidepressant — not Celebrex."

자주 쓰는 표현입니다.

| 상황 | 표현 |
|---|---|
| 다시 말해 달라고 할 때 | "Could you repeat that, please?" |
| 철자 확인 | "Could you spell that for me?" |
| 강도 확인 | "What strength is that?" |
| 수량 확인 | "What's the quantity and the day supply?" |
| 확인 후 복창 | "Let me read that back to you..." |

{{< callout type="info" >}}
**복창(read-back)은 예의가 아니라 절차입니다.** 받아 적은 내용을 그대로 다시 읽어 확인하는 것은 미국 약국의 표준 안전 절차이며, 되묻는다고 감점되지 않습니다. 오히려 되묻지 않고 틀리는 쪽이 문제입니다.
{{< /callout >}}

## 9. 실전 연습

각 처방을 ① 한국어로 해석하고 ② 영어 라벨 문장으로 옮겨 보세요.

| 처방 | 한국어 | 라벨 문장 |
|---|---|---|
| `1 tab po qid pc & hs` | 1정 경구, 매 식후와 취침 시 | Take one tablet by mouth four times daily after meals and at bedtime. |
| `2 gtt ou bid x 7d` | 2방울 양안, 1일 2회, 7일간 | Instill two drops in both eyes twice daily for seven days. |
| `10 mL po q6h prn cough` | 10 mL 경구, 6시간마다 기침 시 | Take ten milliliters by mouth every six hours as needed for cough. |
| `1 tab sl q5min prn CP, max 3` | 1정 설하, 5분마다 흉통 시, 최대 3회 | Place one tablet under the tongue every five minutes as needed for chest pain; do not exceed three doses. |
| `apply thin layer top bid` | 얇게 1일 2회 국소 도포 | Apply a thin layer to the affected area twice daily. |
| `1 cap po daily ac breakfast` | 1캡슐 경구, 매일 아침 식전 | Take one capsule by mouth once daily before breakfast. |
| `inhale 2 puffs q4-6h prn SOB` | 2회 흡입, 4~6시간마다 숨참 시 | Inhale two puffs by mouth every four to six hours as needed for shortness of breath. |
