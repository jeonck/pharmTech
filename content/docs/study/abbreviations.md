처방 입력의 기본입니다. 시험에도 나오고, 실무에서는 매일 씁니다. 아래 표는 통째로 외우세요.

이 약어들을 **영어로 어떻게 읽고 말하는지**는 [처방 읽는 법](../reading/)에서 다룹니다.

## 복용 횟수·시점

| 약어 | 원어 | 뜻 |
|---|---|---|
| qd* | quaque die | 1일 1회 (**위험 약어 — daily로 표기**) |
| bid | bis in die | 1일 2회 |
| tid | ter in die | 1일 3회 |
| qid | quater in die | 1일 4회 |
| qh | quaque hora | 매시간 |
| q4h, q6h, q8h | — | 4·6·8시간마다 |
| qod* | — | 격일 (**위험 약어 — every other day**) |
| prn | pro re nata | 필요 시 |
| stat | statim | 즉시 |
| ac | ante cibum | 식전 |
| pc | post cibum | 식후 |
| hs | hora somni | 취침 시 |
| am / pm | ante/post meridiem | 오전 / 오후 |
| ATC | around the clock | 정해진 간격으로 계속 |

## 눈·귀

| 약어 | 뜻 |
|---|---|
| od | 우안 (right eye) |
| os | 좌안 (left eye) |
| ou | 양안 (both eyes) |
| ad | 우이 (right ear) |
| as | 좌이 (left ear) |
| au | 양이 (both ears) |

{{< callout type="error" >}}
**o = eye, a = ear.** 안약을 귀에, 이용액을 눈에 넣게 하는 라벨 오류는 실제로 발생합니다. 안전을 위해 처방자에게 "right eye"처럼 풀어 쓰도록 요청하는 것이 권장됩니다.
{{< /callout >}}

## 읽기 연습

| 처방 | 해석 |
|---|---|
| `1 tab po bid x 10d` | 1정을 경구로 1일 2회, 10일간 |
| `2 gtt ou qid prn` | 2방울을 양안에 1일 4회 필요 시 |
| `10 mL po q6h prn cough` | 10 mL를 경구로 6시간마다 기침 시 |
| `1 tab sl q5min prn CP, max 3` | 1정 설하 5분마다 흉통 시, 최대 3회 |
| `1 cap po ac tid` | 1캡슐 경구, 식전 1일 3회 |
| `apply top bid to affected area` | 환부에 1일 2회 국소 도포 |
