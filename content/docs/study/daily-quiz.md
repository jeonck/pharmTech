하루 10문제씩 15일이면 한 바퀴를 돕니다. 지식 문항 130개는 고정이고, **계산 문항(3·4일차)은 풀 때마다 숫자가 새로 생성**되므로 답을 외워서 맞힐 수 없습니다. 순서는 [암기 단권화 PDF](/pharmtech-cheat-sheet.pdf)의 14일 계획과 같은 흐름입니다 — 약어 → 계산 → 규제약물 → 약물 → 안전 → 처방 처리 → 법규.

{{< callout type="info" >}}
답을 고르면 바로 채점되고 해설이 나옵니다. 진행 상황과 오답은 **이 브라우저에만** 저장되므로 서버로 전송되지 않습니다. 다른 기기에서는 이어지지 않습니다.
{{< /callout >}}

{{< callout type="warning" >}}
**3·4일차는 매번 다른 문제입니다.** 체중·용량·부피·시간 값이 그때그때 새로 뽑히고, 정답과 오답 보기도 함께 계산됩니다. 출제되는 유형 자체도 매번 달라집니다. **36가지 계산 유형**에서 매번 10개를 뽑아 내므로 **풀이 과정을 익히지 않으면 계속 틀립니다.**
{{< /callout >}}

## 이렇게 쓰세요

1. **하루 한 세트.** 몰아서 풀면 다음 날 남는 것이 없습니다.
2. 채점보다 **해설을 읽는 시간**이 더 중요합니다. 맞힌 문제도 해설은 읽으세요.
3. 70% 미만이면 다음 날로 넘어가지 말고, 해당 주제의 학습 노트를 다시 본 뒤 재도전하세요.
4. 한 바퀴를 돌면 **오답 다시 풀기**로 약한 부분만 반복합니다.
5. 15일 세트를 다 끝내면 **랜덤 10문제**로 섞어서 감을 유지하세요. 랜덤 세트에도 계산 문제가 3개씩 섞여 나옵니다.
6. 계산은 **'새 숫자로 다시 풀기'** 를 반복하세요. 같은 유형이 다른 숫자로 나오므로 손이 익을 때까지 돌리면 됩니다.

## 계산 문제 유형 (3·4일차)

| 구분 | 유형 |
|---|---|
| 단위 환산 | lb↔kg, tsp/tbsp→mL, mL→fl oz, g↔mg, mg→mcg, grain→mg, °F→°C |
| 농도 | % w/v → g, % → mg/mL, mg/mL → %, 연고 % w/w, 비율 강도(1:X) |
| 용량 | 비례식, 정제 개수, 총 조제량, 총 정제 수, 재구성 후 부피, mEq, units→mL |
| 소아 | 체중 기반 1회 용량(mg), 체중 기반 1회 부피(mL) |
| Day supply | 액상, 점안액, 인슐린 바이알, 인슐린 펜, 정제, 흡입기, 재조제 가능일 |
| IV | mL/hr, gtt/min, 총 소요 시간, 남은 시간, 희석(C1V1=C2V2) |
| 약국 경영 | AWP 할인가, 마크업률 |

## 일차별 주제

| 일차 | 주제 |
|---|---|
| 1~2 | 처방 약어 — 횟수·시점, 경로, 눈·귀, 제형, 위험 약어 |
| 3~4 | 계산 36유형 중 매번 10개 *(숫자 자동 생성)* |
| 5 | 규제약물 스케줄과 DEA 서식 |
| 6~10 | 약물 — 심혈관, 내분비, 감염, 통증·정신, 호흡기·소화기 |
| 11~12 | High-alert, LASA, 보관 조건, 투약 오류와 보고 |
| 13 | 처방 입력·처리, NDC, DEA 검증, 보험 청구 |
| 14~15 | 연방 법규, DSCSA·리콜, 시험·TSBP 등록 |

틀린 문제의 주제는 해당 노트에서 다시 확인하세요.
