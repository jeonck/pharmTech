각 문항의 "정답 보기"를 누르기 전에 먼저 답을 정한 뒤 확인하세요. 실제 PTCE는 4지선다이며, 아래는 개념 확인용으로 만든 문제입니다.

## 약물 (Medications)

**1.** Lisinopril은 어떤 계열이며, 가장 특징적인 부작용은?
{{% details title="정답 보기" closed="true" %}}
ACE 억제제. **마른기침**이 특징적이며, 기침 때문에 losartan 같은 ARB로 바꾸는 경우가 많습니다. 임신 중 금기.
{{% /details %}}

**2.** Metoprolol tartrate와 metoprolol succinate를 서로 바꿔 조제해도 되는가?
{{% details title="정답 보기" closed="true" %}}
안 됩니다. tartrate는 속방(IR), succinate는 서방(ER)로 **방출 특성이 다릅니다.** 대표적인 LASA 쌍입니다.
{{% /details %}}

**3.** 미개봉 인슐린의 보관 조건은?
{{% details title="정답 보기" closed="true" %}}
**냉장 2~8°C.** 개봉 후에는 제품별로 정해진 기간 동안 실온 보관이 가능합니다. 냉동은 금지.
{{% /details %}}

**4.** Metronidazole 복용 중 반드시 피해야 할 것은?
{{% details title="정답 보기" closed="true" %}}
**음주.** 디설피람 유사 반응(심한 구역·구토·홍조)이 발생합니다.
{{% /details %}}

**5.** "ER, XR, SR, DR, EC" 표기가 붙은 정제의 공통 주의사항은?
{{% details title="정답 보기" closed="true" %}}
**분쇄·분할 금지.** 방출 제어 구조가 깨져 한꺼번에 약물이 방출됩니다.
{{% /details %}}

**6.** Levothyroxine 복용 지시로 옳은 것은?
{{% details title="정답 보기" closed="true" %}}
**공복(아침 식사 30~60분 전)** 복용, 칼슘·철분·제산제와는 4시간 간격. 브랜드 변경에 민감합니다.
{{% /details %}}

**7.** 다음 중 어미가 알려주는 분류를 짝지으시오: -statin, -prazole, -sartan, -floxacin
{{% details title="정답 보기" closed="true" %}}
-statin: HMG-CoA 환원효소 억제제 / -prazole: PPI / -sartan: ARB / -floxacin: 플루오로퀴놀론
{{% /details %}}

**8.** Nitroglycerin 설하정의 보관 방법은?
{{% details title="정답 보기" closed="true" %}}
**원래의 갈색 유리병에, 뚜껑을 꼭 닫아** 보관합니다. 다른 용기로 옮기거나 필박스에 넣으면 약효가 떨어집니다.
{{% /details %}}

## 연방 법규 (Federal Requirements)

**9.** CII 규제약물의 리필은 몇 회까지 가능한가?
{{% details title="정답 보기" closed="true" %}}
**0회.** CII는 리필이 불가능합니다. CIII·CIV는 6개월 내 최대 5회.
{{% /details %}}

**10.** DEA 번호 `BQ7654321`의 체크 디지트를 검증하시오.
{{% details title="정답 보기" closed="true" %}}
1·3·5번째: 7+5+3 = 15 / 2·4·6번째: 6+4+2 = 12 → ×2 = 24 / 합계 39 → 일의 자리 **9**.
마지막 자리가 1이므로 **유효하지 않은 번호**입니다.
{{% /details %}}

**11.** CII 의약품을 주문할 때 사용하는 서식은?
{{% details title="정답 보기" closed="true" %}}
**DEA Form 222**(또는 전자 시스템 CSOS). 폐기는 Form 41, 분실·도난 보고는 Form 106.
{{% /details %}}

**12.** DSCSA에서 요구하는 T3 문서 세 가지는?
{{% details title="정답 보기" closed="true" %}}
**TI**(Transaction Information), **TH**(Transaction History), **TS**(Transaction Statement).
{{% /details %}}

**13.** 잘못된 성분이 들어가 사망 위험이 있는 제품의 리콜 등급은?
{{% details title="정답 보기" closed="true" %}}
**Class I.** Class II는 일시적·가역적 위해, Class III는 위해 가능성이 낮은 경우입니다.
{{% /details %}}

**14.** 환자 상담 제공 의무를 규정한 법은?
{{% details title="정답 보기" closed="true" %}}
**OBRA '90.** DUR(약물 사용 검토) 요건도 함께 규정했습니다.
{{% /details %}}

**15.** 처방약과 일반약을 구분하고 구두 처방·리필을 허용한 법은?
{{% details title="정답 보기" closed="true" %}}
**Durham-Humphrey Amendment (1951).**
{{% /details %}}

**16.** 슈도에페드린 판매를 제한하는 법은?
{{% details title="정답 보기" closed="true" %}}
**CMEA (2005).** 카운터 뒤 보관, 신분증 확인, 구매 한도, 판매 기록 보관이 요구됩니다.
{{% /details %}}

## 환자 안전 (Patient Safety & QA)

**17.** 처방전에 `1.0 mg`이라고 쓰여 있다. 무엇이 문제인가?
{{% details title="정답 보기" closed="true" %}}
**후행 0(trailing zero).** 소수점이 안 보이면 10 mg으로 읽혀 10배 과량이 됩니다. `1 mg`으로 써야 합니다.
{{% /details %}}

**18.** High-alert 약물의 예를 세 가지 드시오.
{{% details title="정답 보기" closed="true" %}}
인슐린, 항응고제(warfarin·heparin), 오피오이드, 농축 KCl 주사, 화학요법제 등.
{{% /details %}}

**19.** 조제 오류를 발견했을 때 테크니션의 첫 행동은?
{{% details title="정답 보기" closed="true" %}}
**즉시 약사에게 보고합니다.** 혼자 수정하거나 숨기지 않습니다.
{{% /details %}}

**20.** predniSONE / predniSOLONE 같은 표기 방식을 무엇이라 하는가?
{{% details title="정답 보기" closed="true" %}}
**Tall Man Lettering.** LASA 약물 혼동을 줄이기 위한 표기입니다.
{{% /details %}}

**21.** 환자에게 도달하기 전에 발견된 오류를 부르는 말은?
{{% details title="정답 보기" closed="true" %}}
**Near miss(아차사고).** 보고 대상이며, 시스템 개선의 중요한 자료가 됩니다.
{{% /details %}}

## 처방 처리 (Order Entry & Processing)

**22.** NDC 번호의 세 구획은 각각 무엇을 뜻하는가?
{{% details title="정답 보기" closed="true" %}}
5-4-2 형식으로 **제조사(labeler) – 제품(product) – 포장(package)** 입니다.
{{% /details %}}

**23.** "Refill Too Soon" 거절이 떴다. 어떻게 대응하는가?
{{% details title="정답 보기" closed="true" %}}
보험상 조제 가능 날짜를 확인해 환자에게 안내합니다. 여행 등 사유가 있으면 보험사에 **vacation override**를 요청할 수 있습니다.
{{% /details %}}

**24.** 보험 청구에 필요한 카드 정보 네 가지는?
{{% details title="정답 보기" closed="true" %}}
**BIN, PCN, Group, Member ID** (+ person code).
{{% /details %}}

**25.** DAW 1은 무엇을 뜻하는가?
{{% details title="정답 보기" closed="true" %}}
**처방자가 브랜드를 지정**한 경우입니다. DAW 0은 대체 허용(기본), DAW 2는 환자가 브랜드를 요구한 경우.
{{% /details %}}

## 계산

**26.** 125 mg/5 mL 현탁액으로 200 mg을 투여하려면 몇 mL인가?
{{% details title="정답 보기" closed="true" %}}
125/5 = 200/x → x = (200 × 5) ÷ 125 = **8 mL**
{{% /details %}}

**27.** 0.45% NaCl 1,000 mL에 들어 있는 NaCl의 양은?
{{% details title="정답 보기" closed="true" %}}
0.45 g/100 mL × 1,000 mL = **4.5 g**
{{% /details %}}

**28.** 10 mL 점안액을 양안에 2방울씩 하루 3회 넣는다. day supply는? (1 mL = 20 방울)
{{% details title="정답 보기" closed="true" %}}
총 200 방울, 하루 사용 = 2 × 2 × 3 = 12 방울 → 200 ÷ 12 = 16.6 → **16일분**
{{% /details %}}

**29.** 66 lb 소아에게 15 mg/kg/day를 3회 분할 투여한다. 1회 용량은?
{{% details title="정답 보기" closed="true" %}}
66 ÷ 2.2 = 30 kg → 30 × 15 = 450 mg/day → 450 ÷ 3 = **150 mg**
{{% /details %}}

**30.** 500 mL를 4시간에 투여한다. drop factor가 20 gtt/mL일 때 gtt/min은?
{{% details title="정답 보기" closed="true" %}}
(500 × 20) ÷ 240분 = 41.67 → 약 **42 gtt/min**
{{% /details %}}
